# Literature scan: speeding up Strata single-user decode (2026-10-20)

Method: web search plus abstract/page fetches only. Most numbers come from abstracts or secondary pages; full PDFs were not read. "Not reported" means the pages I read did not state it. Several 2026 arXiv/alphaxiv IDs (DraftExpert, AcceptMoE, SPICE, 2603.19289) are recent and I have not verified peer-review status.

Setup reminder: IQ3_XXS 125B MoE, 12 GB VRAM (3153 expert slots), 20 GiB RAM LRU tier (12448 slots), SSD for the rest, CPU computes misses, MTP spec 6/mtp_max 3. Bottleneck: SSD read volume (r = -0.992 vs tok/s), 77% of warm RAM-tier misses are capacity misses.

## Notes on exactness
- Exact: #6, #11, #13 (and #9 mostly).
- Output-changing: #1, #2, #3, #4, #5, #7, #8, #10. These need a quality gate (replay the same prompts, compare token agreement and task success) before they can be called a win.

## Recommended next experiments

1. Cache-biased routing, misses-only (from #1 plus #4). Add an env knob to add a bonus delta to router logits of experts resident in VRAM/RAM (try delta in {0, 0.25, 0.5, 1.0} on logit scale, and a top-k membership guard so the top-1 expert is never replaced). Measure on a fixed recorded Hermes trace (6-10k prompt, fixed seed, greedy) with a deterministic replay harness: SSD bytes/window, miss/layer, token agreement versus baseline, then tok/s over 5 runs per setting. Success: SSD reads -25% with token agreement >=97%.
2. Gate-weight skipping for CPU-miss experts only (#4). Skip (or drop from the sum) a missing expert when its normalized gate weight < tau, tau in {0.01, 0.02, 0.05}. Replay the same trace and log how many misses fall below each tau first (a pure counting pass, no change in output) to estimate ceiling before building. Success: >=20% of misses below tau with agreement >=98%.
3. Quality-neutral accounting pass for lower-bit cold copies (#5), offline only: histogram per-expert hit frequency from existing logs to see how much SSD traffic comes from the coldest experts; if >50% of SSD bytes come from experts used <N times per 1000 windows, quantizing only those to IQ2_XXS is worth a pack-file prototype. No remote benchmark needed for the counting step.

Also: read the KTransformers expert-deferral section in the SOSP PDF (https://madsys.cs.tsinghua.edu.cn/publication/ktransformers-unleashing-the-full-potential-of-cpu/gpu-hybrid-inference-for-moe-models/SOSP25-chen.pdf) to decide if it maps onto the 12.4 ms GPU-wait / 11.4 ms CPU-compute overlap.

## Limits of this scan
HOBBIT thresholds, MoE-Infinity, ExpertFlow, ProMoE, AdapMoE, Pre-gated MoE, SwapMoE, MoE-Lightning (batch-oriented, not relevant to single-user decode) were not read in detail. MoE-Lightning is aimed at throughput batching and was excluded on that basis only, not from reading it.
